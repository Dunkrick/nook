# Components

## Workspace shell

Owns the canvas environment and contains all workspace furniture. It has no product-state behavior.

## Floating toolbar

Uses the overlay material and contains the wordmark plus contextual actions. It remains visually quieter than thoughts.

## Thought card

An artifact with a color role (`--artifact-1` through `--artifact-4`), strong boundary, and material elevation. Selection adds an outline; dragging changes elevation. The card API and interactions are unchanged by DS-1.

## Draft card and empty workspace

Both are artifacts. A draft signals incompleteness with a dashed boundary. The empty workspace uses two notes to invite the first thought without making the desk feel empty or broken.

## Overlays

Selection and insight tools use overlay elevation, translucent artifact material, and a short settle entrance. They never introduce a new palette or typography scale.
