# Typography

Nook uses Plus Jakarta Sans for UI and reading. IBM Plex Mono is reserved for small ordered metadata, such as thought numbers.

| Role | Token | Use |
| --- | --- | --- |
| Display | `--type-display-size` | Rare high-emphasis moments |
| Page / empty-state title | `--type-title-size` | Primary screen statement |
| Section title | `--type-section-size` | Panel headings |
| Artifact body | `--type-artifact-size` | Thought text |
| Body | `--type-body-size` | Paragraphs and input |
| Label | `--type-label-size` | Buttons and supportive copy |
| Hint | `--type-hint-size` | Secondary metadata |
| Overline | `--type-overline-size` | Eyebrows and card IDs |

Headings use `--leading-heading` and `--tracking-tight`; all other content uses `--leading-body`. Do not create visual hierarchy with arbitrary font sizes.
