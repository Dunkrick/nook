# Motion

Motion explains a change in spatial state. It should be brief, soft, and interruptible.

| Token | Duration | Use |
| --- | --- | --- |
| `--motion-lift` | 180ms | Hover and small control feedback |
| `--motion-settle` | 220ms | Placement, panel entrance, card movement |
| `--motion-pop` | 350ms | Reserved for rare celebratory moments |

Do not animate idle surfaces continuously. Dragged cards respond immediately; animations resume only after release. Respect reduced-motion preferences in future motion-heavy additions.
