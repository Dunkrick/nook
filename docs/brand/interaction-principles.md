# Nook Interaction Principles

Nook is a quiet place to think.

Every interaction should reduce cognitive load rather than demand attention.

Objects should behave like physical paper, not interface widgets.

---

## 1. Resting

A resting thought should feel calm, confident and available.

It should never compete for attention.

### Principles

- Warm paper surface
- Minimal shadow
- Gentle rotation
- Generous spacing
- No loud borders

Users should feel:

"I can come back to this whenever I need."

---

## 2. Hover

Hover is acknowledgement.

Not celebration.

The card quietly responds to the user's curiosity.

### Principles

- Slight lift
- Slightly stronger shadow
- Tiny rotation correction
- No dramatic scaling

Users should feel:

"The card noticed me."

---

## 3. Drag

Dragging should feel like lifting a sheet of paper.

The pointer and the card should remain perfectly attached.

### Principles

- Shadow becomes deeper
- Rotation straightens
- Movement is immediate
- Release settles naturally

Users should feel:

"I'm moving a thought."

---

## 4. Selection

Selection is about creating relationships.

Selected thoughts become clearer.

Unselected thoughts quietly step back.

### Principles

- Selected thoughts gain emphasis
- Remaining thoughts lose emphasis
- Attention is guided, never forced

Users should feel:

"These thoughts belong together."

---

## 5. Editing

Editing is a conversation with an existing thought.

The transition should feel seamless.

### Principles

- Cursor appears immediately
- Save quietly settles back
- No jarring layout changes

Users should feel:

"My thought evolved."

---

## 6. Reflection

Reflection is not a chatbot.

Reflection is a pause.

### Principles

- Calm entrance
- Structured information
- One clear takeaway

Users should feel:

"I understand what matters next."

---

## Motion Vocabulary

Fade In
→ Something new appeared.

Lift
→ This object can be interacted with.

Settle
→ The action is complete.

Focus
→ This deserves attention.

Fade Back
→ Reduce visual noise.

---

## Guiding Principle

Nothing in Nook should ask for attention.

Everything should earn it.
