# How should a card exist on a wall?

### 1. Context
- We are changing the current dream wall being rendered as a vertical list into a spatial wall, where position carries meaning

### 2. Decision
- Adding co-ordinates to every card

### 3. Consequences
- Positives
    - Enables wall-layout
    - Enables drag and drop
    - Enables future zooming
- Negatives
    - Existing rows need defaults
    - API changes slightly

### 4. Alternatives considered
- Ordered list
- Kanban columns
- Categories
