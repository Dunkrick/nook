Dream Wall v2.5 transforms the project from a learning backend into a maintainable engineering system.

This release focuses on architecture rather than features.

Business logic is now isolated from HTTP, validation is reusable, database access is abstracted through Prisma, and the project has been migrated completely to TypeScript.

The result is a backend that is significantly easier to extend, test and maintain.


## Repository Improvements

- Routes reduced by ~40%
- SQL statements reduced from 4 endpoints to 0
- 100% backend migrated to TypeScript
- 100% CRUD migrated to Prisma
- Zero duplicated validation logic
