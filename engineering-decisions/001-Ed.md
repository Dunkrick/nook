# ED-001: Why are we using Node.js?

## Problem

We want to build backend systems using JavaScript.

## Options

- PHP
- Python
- Java
- Go
- Node.js

## Decision

Node.js

## Why?

- Same language across frontend and backend
- Excellent ecosystem
- Great support for APIs
- Strong AI SDK ecosystem
- Huge startup adoption
- TypeScript support

## Trade-offs

- Single-threaded execution model
- Async programming has a learning curve
- CPU-heavy work requires different strategies
